05 / How to explain it in your demonstration

  1. Round Robin: each ready process receives the CPU for at most one time quantum. If it is not complete, it returns to the end of the ready queue.
  2. Context-switch overhead: switching to a different process consumes 1 ms in this assignment. That interval is shown separately and does not count as useful process execution.
  3. Completion time (CT): the time at which a process finishes.
  4. Turnaround time (TAT): CT − arrival time.
  5. Waiting time (WT): TAT − burst time.
  6. Response time (RT): first CPU start time − arrival time.
  7. CPU efficiency: total burst time ÷ total elapsed schedule time × 100%. Context-switch intervals are included in elapsed time.
  8. Compare quantum 2 ms and 4 ms. A smaller quantum usually gives processes more frequent turns but can add more context-switch overhead; a larger quantum can reduce overhead but may delay other processes.

Note: this is a scheduling model, not a real operating-system kernel. Context-switch duration is assumed constant at 1 ms, as specified in the assignment.
